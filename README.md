## About This Repository

This repo helps **AI/ML Engineers** build the scripting skills the job actually
demands — the everyday code that powers data pipelines, training jobs, model
deployment, automation, and operations.

It is organized **by language**. Each language lives in its own top-level folder
with its own scripts, lessons, and README. Start with the one you need today and
add the others as you grow.

Created and maintained by **Emmanuel Naweji** — AI/ML/Robotics practitioner.

## Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/Here2ServeU/scripting.git
cd scripting

# 2. Open the language you want to learn
cd python          # then follow python/README.md
```

For Python specifically, see [**python/README.md**](python/README.md) for the
virtual-environment setup and how to run every script.

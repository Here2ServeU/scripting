# Practice Tests

Four timed tests that cover every pattern taught in the course.

| File | Focus | Difficulty |
|------|-------|-----------|
| `mock1.py` | Strings and Counting | Easy–Medium |
| `mock2.py` | Lists and Dictionaries | Easy–Medium |
| `mock3.py` | Sliding Window and Set Operations | Easy–Medium |
| `mock4.py` | Full DevOps Test — the hardest one | Medium–Hard |

## How to Use

1. Set a 70-minute timer.
2. Open the file. Read each question.
3. Write your code in the blank function **before** reading the answer at the bottom.
4. Run the file. All assertions must pass.

```bash
python tests/mock1.py
python tests/mock2.py
python tests/mock3.py
python tests/mock4.py
```

## You Are Ready When...

You can finish `mock4.py` in 70 minutes without looking at the answers, and all assertions pass.

> *"When you can write all 5 patterns from memory, you are ready."*
> — Emmanuel Naweji
